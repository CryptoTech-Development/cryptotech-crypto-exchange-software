# CryptoTech Support

CryptoTech provides technical support and development services for businesses using the CryptoTech cryptocurrency exchange software platform.

## Product Information

CryptoTech is self-hosted cryptocurrency exchange software delivered to licensed customers with complete source-code access.

The platform can include:

- Crypto exchange matching engine
- Real-time order books
- Multi-currency wallets
- Hot and cold wallet architecture
- KYC and AML integrations
- P2P crypto trading
- Liquidity integrations
- REST and WebSocket APIs
- Exchange admin panel
- Mobile applications
- Self-hosted deployment
- Custom integrations and development
