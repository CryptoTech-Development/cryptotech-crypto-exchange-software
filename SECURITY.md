# Security Policy

## Reporting a Security Issue

Security is an important part of the CryptoTech cryptocurrency exchange software platform.

If you discover a potential security vulnerability related to CryptoTech, please report it privately rather than opening a public GitHub issue.

Please include as much relevant information as possible, such as:

- A description of the vulnerability
- The affected component or feature
- Steps required to reproduce the issue
- Expected and actual behavior
- Screenshots or logs when relevant
- Potential security impact
- Any suggested mitigation or fix

## Private Disclosure

Please send security-related reports through the official CryptoTech support channels:

**Website:** https://cryptotech.exchange/  
**Support:** https://cryptotech.exchange/support/

Do not publish security vulnerabilities, proof-of-concept exploits, sensitive configuration details, credentials, private keys, API secrets, or customer information in this public repository.

## Commercial Product Security

CryptoTech is commercial cryptocurrency exchange software distributed to licensed customers with complete source-code access.

This public repository contains product information and technical overview material only. The proprietary CryptoTech application source code is not publicly distributed through this repository.

Security configuration can vary depending on the customer's infrastructure, deployment architecture, integrations, wallet configuration, and operational requirements.

## Responsible Disclosure

We appreciate responsible security research and good-faith vulnerability reporting.

Please allow reasonable time for investigation and remediation before publicly disclosing a reported security issue.
